# MANUAL DO USUÁRIO — Plataforma GWDC

Guia de uso do website institucional e dos MVPs da GW Digital Company.

---

## 1. Website institucional

### Página inicial
- **Hero:** apresentação da GWDC com chamada para ação (Soluções, Produtos)
- **Manifesto:** missão, visão e valores da empresa
- **Verticais:** atalhos para as 8 áreas de atuação
- **Produtos em destaque** e chamadas para MVPs e carreiras

### Navegação principal
| Menu | Conteúdo |
| --- | --- |
| Início | Página principal |
| Sobre | História, missão, valores, equipe |
| Soluções | 8 verticais com problema → transformação |
| Produtos | 18 produtos com detalhes técnicos |
| MVPs | Demonstrações navegáveis (requer login) |
| Parceiros | Ecosistema e depoimentos |
| Carreiras | Vagas abertas |
| Blog | Artigos da GWDC |
| Contato | Formulário e canais |

### Produtos
Cada página de produto apresenta: objetivo, público-alvo, funcionalidades, fluxo de operação,
tecnologias utilizadas, métricas de referência e status (Conceito / Piloto / Lançado).

### Blog
Artigos com autor, data e leitura estimada. Links relacionados no rodapé do artigo.

### Contato
Formulário de contato (nome, e-mail, assunto, mensagem) — simulado no ambiente de demonstração.

## 2. MVPs (demonstrações navegáveis)

### Acesso
1. Clique em **"Experimentar Demo"** (botão em Produtos, MVPs ou no rodapé)
2. Na tela de login, entre com **`demo@gwdc.gw`** e senha **`demo1234`**
   (ou crie uma sessão com qualquer e-mail válido + senha de 6+ caracteres)
3. Você é redirecionado ao dashboard do primeiro produto

### Navegação no dashboard
- **Menu lateral:** alterna entre produtos do mesmo setor (ex.: Governo → GW-Docs, GW-ID, eProcura)
- **Topo:** seletor de produto, modo claro/escuro, perfil do usuário, sair
- **Conteúdo:** indicadores (KPIs) → alertas → gráficos (tendência, barras, pizza, sparkline) →
  tabela detalhada → seção especial do produto (se houver)

### Seções especiais por produto
| Produto | Seção especial |
| --- | --- |
| GW-School | Calendário acadêmico |
| GW-Bank / ePIX | Gerador de QR Code (PIX) |
| GW-Mobil | Mapa de rastreamento de viaturas |
| GW-Energy | Medidores climáticos |
| GW-Health | Ocupação de leitos |
| GW-Docs | Relatório de IA (extração de documentos) |

### Assistente virtual (IA)
Botão flutuante **"Assistente GW"** em todos os dashboards:
- **OCR:** "extrair" documentos
- **Tradução:** textos entre crioulo/português/inglês
- **Fraude:** validar transações suspeitas
- **Predição:** projeções de séries
- **Resumo:** síntese de relatórios
- Use as **sugestões rápidas** ou digite sua pergunta

### Encerrar sessão
Clique no perfil (canto superior direito) → **Sair**. A sessão local é removida.

## 3. Modo claro / escuro

O botão de tema (topo do dashboard e rodapé do site) alterna instantaneamente entre os dois
modos — a preferência fica salva no navegador.

## 4. Dúvidas frequentes

| Pergunta | Resposta |
| --- | --- |
| Os dados dos MVPs são reais? | Não — são dados fictícios realistas para demonstração |
| Posso usar meu e-mail? | Sim, qualquer e-mail válido cria sessão de demonstração |
| Os gráficos atualizam sozinhos? | Os dados são fixos nesta versão demo |
| Onde vejo o código? | Repositório oficial da GWDC + documentação em `docs/` |
